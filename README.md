# invariancetech.info

Website of the Technical Invariance Authority: an open archive of world Marxism and a workshop for communist technology.

Plain static files, no build step. Cloudflare Pages deploys this repository on every push.

- `index.html` homepage
- `archive/` Index of Marxists
- `arcade/` simulations
- `shop/` TIA Supply Depot
- `assets/` images, video and icons
